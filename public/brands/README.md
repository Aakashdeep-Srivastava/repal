# Brand logos for the "How it flows" rewards panel

Drop **official** brand logo files here and the landing page's rewards panel
(`components/landing/Landing.tsx` → `BrandLogo`) will show them automatically.
Until a file exists, each chip falls back to the brand name as plain text.

Use the exact filenames below (SVG preferred; PNG with transparent background
also works — just keep the same name with a `.png`/`.svg` extension and update
the `file=` prop if you change the extension):

| Chip          | Filename          |
| ------------- | ----------------- |
| Visa          | `visa.svg`        |
| Mastercard    | `mastercard.svg`  |
| American Express | `amex.svg`     |
| Discover      | `discover.svg`    |
| Gmail         | `gmail.svg`       |
| Amazon        | `amazon.svg`      |
| Starbucks     | `starbucks.svg`   |
| Apple         | `apple.svg`       |
| Chase         | `chase.svg`       |
| Citi          | `citi.svg`        |
| Capital One   | `capitalone.svg`  |

**Where to get them:** download from each brand's official press / brand-assets
page, or from a logo set whose license permits this use. These are third-party
trademarks — make sure your usage complies with each brand's guidelines. This
repo intentionally ships none of them.
